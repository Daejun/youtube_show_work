## Overview

The Android Show: XR Edition is a roughly 30-minute livestream from Android Developers hosted by Sameer that introduces Android XR as a unified platform for extended reality devices, demonstrates new Galaxy XR headset features, previews XREAL's Project Aura wired XR Glasses, shows prototype AI Glasses built with Warby Parker and Gentle Monster, and announces Developer Preview 3 of the Android XR SDK with new APIs and Jetpack libraries for glasses development.

### Simplified Development (21:52–28:00)

**Facts**
- Matthew says Android XR uses the APIs and tools developers already know from building adaptive apps [22:01].
- Matthew announces Developer Preview 3 of the Android XR SDK [22:19].
- Matthew says the release includes new features for building rich 3D scenes such as spatial animations with soft head locking and transitions [22:43].
- Matthew says it has become easier to adapt existing UIs with Material 3 components like dialogs and navigation bars that automatically transform into spatial XR elements [22:51].
- Matthew says new APIs allow apps to detect a device's field of view, and developers can test fields of view in the XR Emulator in Android Studio [23:18].
- Matthew says development is opening today for both AI Glasses and Display AI Glasses [23:25].
- Matthew says ARCore for Jetpack XR was introduced last year, and ARCore's geospatial capabilities are being added [23:58].
- Matthew says the Visual Positioning Service provides directions based on orientation, the Geospatial API enables content triggers and location-specific actions, and ARCore motion tracking enables responses to user movement like a head tilt [24:02].
- Matthew introduces Jetpack Glimmer, a Compose UI Toolkit for AI Glasses with components like cards, lists, and stacks [24:36].
- Matthew introduces the Jetpack Projected Library, which lets developers bring an existing Android mobile app directly to AI Glasses and manage audio and camera access [24:55].
- Matthew says the team has collaborated with the Firebase AI Logic team to make the Gemini Live API work with AI Glasses [25:14].
- Amit, who leads the rider-product team at Uber, demos bringing the Uber experience to glasses [25:28].
- Amit shows that after booking an Uber, riders can see trip status and ETA in their view [26:05].
- Amit shows wayfinding in glasses providing contextual directions, and the glasses showing the driver's license-plate number at the pickup curb [26:32].
- Matthew says developers can test apps on the XR Emulator in Android Studio and can go to developer.android.com to share feedback [27:33].
